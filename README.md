# React E-Commerce App
## Main features

- Home page
- Product listing
- Search products
- Category filtering
- Sort by price/name
- Product details
- Add to cart
- Increase/decrease quantity
- Wishlist
- Login/Register
- Checkout page
- Order history
- Responsive Bootstrap UI
- API integration using Axios
- Loading/error handling
- Context API for cart/auth state
- React Router
- LocalStorage persistence
